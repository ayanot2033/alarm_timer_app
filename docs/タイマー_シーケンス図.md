# タイマーシーケンス図

%%{init: {
  "theme": "dark"
}}%%

sequenceDiagram

    actor ユーザー
    participant タイマー画面
    participant タイマー処理
    participant 通知処理

    ユーザー->>タイマー画面: 時間・分・秒を設定
    タイマー画面->>タイマー処理: 設定時間を渡す

    ユーザー->>タイマー画面: 開始ボタンを押下
    タイマー画面->>タイマー処理: カウントダウン開始を要求
    タイマー処理->>タイマー処理: カウントダウンを開始

    loop 1秒ごと
        タイマー処理->>タイマー画面: 残り時間を更新
    end

    タイマー処理->>通知処理: タイマー終了を通知
    通知処理->>タイマー画面: 終了通知を表示

    alt カウントダウン中に再読み込み・再起動した場合
        ユーザー->>タイマー画面: 再読み込み・再起動
        タイマー画面->>タイマー処理: タイマーを終了
        タイマー処理-->>タイマー画面: 開始前の状態に戻す

    else 一時停止中に再読み込み・再起動した場合
        ユーザー->>タイマー画面: 再読み込み・再起動
        タイマー画面->>タイマー処理: タイマー状態を破棄
        タイマー処理-->>タイマー画面: 開始前の状態に戻す

    else 終了通知中に再読み込み・再起動した場合
        ユーザー->>タイマー画面: 再読み込み・再起動
        タイマー画面->>通知処理: 通知終了を要求
        通知処理->>通知処理: 通知音を停止
        通知処理-->>タイマー画面: 通知表示を終了
        タイマー画面-->>ユーザー: 開始前の状態を表示
    end
