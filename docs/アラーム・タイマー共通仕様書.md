# 共通要求仕様書

## 1. 概要

タイマー機能およびアラーム機能に共通する仕様を定義する


## 2. 対象環境

- 使用言語: TypeScript
- 使用ツール: Vite, VSCode
- 動作環境:
  - Google Chrome 最新版
  - Microsoft Edge 最新版
- データ保存: LocalStorageを利用する


## 3. 共通機能仕様

### 3.1 画面切り替え

- タイマー画面とアラーム画面を切り替えられる


### 3.2 同時動作

- タイマー機能とアラーム機能は独立して動作し、同時に利用できる
- 画面を切り替えても、動作中のタイマーおよびアラームは継続する


### 3.3 通知

- 通知中に画面を切り替えても、通知音および通知表示は継続する
- 通知音は同時に複数再生しない
- 複数の通知が発生した場合は、発生順に通知する


### 3.4 入力方式

- 時刻は各単位ごとに個別の選択欄から設定する
- 設定可能な範囲外の値は選択できない
