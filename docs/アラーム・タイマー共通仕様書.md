# 共通要求仕様書

## 1. 概要

タイマー機能およびアラーム機能に共通する仕様を定義する


## 2. 対象環境

- 使用言語: TypeScript
- 使用ツール: Vite, VSCode
- 動作環境:
  - Google Chrome 最新版
  - Microsoft Edge 最新版
- データ保存: LocalStorageを利用する



## 2. ペルソナ
自宅で資格試験の勉強をしており、PCを使って学習することが多い。
集中して作業する時間と休憩時間を区切るためにタイマーを利用している。
また、決まった時刻に予定や休憩を知らせるためにアラームを利用している。
タイマーを使用しながらアラームを待機させるなど、複数の時間管理を同時に行いたい。



## 3. 利用シーン
学習や作業時間を計測するためにタイマーを使用する
決まった時刻に通知を受けるためにアラームを使用する
タイマーを使用しながら、別の予定時刻をアラームで管理する
画面を切り替えながら、タイマーやアラームを継続して利用する





## 4. 共通機能仕様

### 4.1 画面切り替え

- タイマー画面とアラーム画面を切り替えられる


### 4.2 同時動作

- タイマー機能とアラーム機能は独立して動作し、同時に利用できる
- 画面を切り替えても、動作中のタイマーおよびアラームは継続する


### 4.3 通知

- 通知中に画面を切り替えても、通知音および通知表示は継続する
- 通知音は同時に複数再生しない
- 複数の通知が発生した場合は、発生順に通知する


### 4.4 入力方式

- 時刻および時間は、各単位ごとに個別の選択欄から設定する
- 選択欄には、各機能で設定可能な範囲の値のみを表示する
- 時刻および時間の表示形式・設定可能範囲は、各機能の仕様に従う
