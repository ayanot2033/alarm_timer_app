# 共通要求仕様書

## 1. 概要

タイマー機能およびアラーム機能に共通する仕様を定義する


## 2. 対象環境

- 使用言語: TypeScript
- 使用ツール: Vite, VSCode
- 動作環境:
  - Google Chrome 最新版
  - Microsoft Edge 最新版



## 2. ペルソナ
- 自宅でPCを使って資格試験の勉強をしている
- 集中時間と休憩時間の管理にタイマーを利用している
- 予定や休憩を知らせるためにアラームを利用している
- タイマーとアラームを同時に利用したい



## 3. 利用シーン
- 学習や作業時間を計測するためにタイマーを使用する
- 決まった時刻に通知を受けるためにアラームを使用する
- タイマーを使用しながら、別の予定時刻をアラームで管理する
- 画面を切り替えながら、タイマーやアラームを継続して利用する





## 4. 共通機能仕様

### 4.1 起動・初期表示

- 初回起動時はアラーム画面を表示する
- 再読み込み・再起動した場合は、最後に表示していた画面を表示する


### 4.2 画面切り替え

- タイマー画面とアラーム画面を切り替えられる
- アラーム通知中は、通知を停止するまでタイマー画面へ切り替えられない
- タイマー終了通知中は、通知を停止するまでアラーム画面へ切り替えられない


### 4.3 同時動作

- タイマー機能とアラーム機能は独立して動作し、同時に利用できる
- 画面を切り替えても、動作中のタイマーおよびアラームは継続する


### 4.4 通知

- 通知中に画面を切り替えても、通知音および通知表示は継続する
- 通知音は同時に複数再生しない
- 複数の通知が発生した場合は、発生順に1件ずつ通知する
- 通知中に別の通知が発生した場合は、現在の通知を終了した後に通知する
- ユーザーが停止操作を行った場合、アラーム音を停止し、通知表示を終了する
- ユーザーが停止操作を行わない場合、通知発生から3分経過するとアラーム音を自動停止する
- タイマーとアラームの通知が同時に発生した場合は、現在表示している画面の機能を優先して通知する
- アラーム音が自動停止した場合、通知表示は画面上に残す


### 4.5 再読み込み・再起動

- ブラウザを再読み込み・再起動した場合、動作中のタイマーおよびアラームの状態を引き継がない
- ブラウザを再読み込み・再起動した場合、通知音および通知表示を終了する


### 4.6 入力方式

- 時刻および時間は、各機能に応じた単位ごとに個別の選択欄から設定する
- 選択欄には、各機能で設定可能な範囲の値のみを表示する
- 時刻および時間の表示形式・設定可能範囲は、各機能の仕様に従う
