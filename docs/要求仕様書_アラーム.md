# アラーム　要求仕様書

## 1. 概要

- ブラウザ上で動作するアラーム機能を作成する
- ユーザーはアラーム時刻を設定し、設定した時刻になると通知を行う



## 2. 機能仕様

### 2.1 初期状態

- アラームは最大５件まで登録できる
- 登録済みアラームがある場合は一覧を確認できる
- 登録済みアラームが存在する場合、アラーム一覧から各アラームの有効・無効状態を切り替えれる


### 2.2 アラーム登録

- 24時間制の時間選択欄を確認できる
- 0～23までの時間を選択できる
- 0～59までの分を選択できる
- 設定した時間・分をアラームとして登録できる
- 登録時は初期状態を有効状態になる
- 入力内容をキャンセルできる
- 登録済みのアラームと同じ時刻のアラームは登録できない
- アラームは５件まで登録できる


### 2.3 アラーム管理

- 登録済みアラームごとに有効・無効状態を変更できる
- 有効状態のアラームのみ設定時刻になると通知する
- 無効状態のアラームは設定時刻になっても通知しない


### 2.4 アラーム編集

- 登録済みのアラームの時間と分を編集できる


### 2.5 アラーム削除

- 登録したアラームを削除できる
- アラーム削除時は確認ダイアログが表示される


### 2.6 アラーム鳴動

- 設定時刻になるとアラーム音を再生する
- アラーム音を停止できる
- 鳴動中にブラウザを再読み込みした場合、アラーム音および通知を終了し、アラーム一覧に戻る
- 鳴動中にタブを閉じた場合、アラーム音および通知を終了する
- スヌーズできる
- 複数の通知が発生した場合、アラーム音は同時に複数再生しない
- 複数のアラーム通知が発生した場合は、発生順に通知する
- 各通知は個別に停止またはスヌーズする
- 停止した通知以外に鳴動中のアラームがある場合、次のアラーム音を再生する
- アラームを停止すると、アラーム一覧に戻る



### 2.7 スヌーズ機能

- スヌーズにすると、3分後に再通知する
- スヌーズは最大3回まで実行できる
- スヌーズ中はアラームの編集および削除はできない
- 3回目の再通知後、3分間ユーザーによる停止操作が行われない場合は、自動でアラーム音と通知を停止する


### 2.8 再読み込み・再起動

- 鳴動中にブラウザを再読み込み・再起動した場合、アラーム音および通知を終了し、アラーム一覧に戻る
- 鳴動中にタブを閉じた場合、アラーム音および通知を終了する


### 2.9 データ管理

- ブラウザを再読み込みしても、保存したアラーム設定を復元する
- タブを閉じて再度起動しても、保存したアラーム設定を復元する



## 3. 操作例

| 操作                   | 表示・結果                        |
| -------------------- | ---------------------------- |
| 追加ボタンを押す             | アラーム設定画面を表示する                |
| 時間・分を選択する            | 選択した時刻を表示する                  |
| 保存ボタンを押す             | アラーム一覧へ追加する                  |
| キャンセルボタンを押す          | 入力内容を破棄し、アラーム一覧画面へ戻る         |
| 既に登録済みの時刻を保存する       | 「同じ時刻のアラームは既に登録されています。」を表示する |
| 登録件数が5件の状態で追加する      | 「登録件数は5件までです。」を表示する          |
| 編集ボタンを押す             | アラーム編集画面を表示する                |
| 時刻を変更して保存する          | 変更した内容でアラーム一覧を更新する           |
| 編集中にキャンセルする          | 編集前の設定内容に戻る                  |
| ON/OFFボタンを押す         | アラームの有効・無効状態を切り替える           |
| 削除ボタンを押す             | 削除確認ダイアログを表示する               |
| 削除確認で削除を選択する         | アラームを削除し、アラーム一覧をに戻る           |
| 削除確認でキャンセルを選択する      | アラームを削除せずアラーム一覧へ戻る             |
| 設定時刻になる              | 通知を表示し、アラーム音を再生する        |
| 停止ボタンを押す             | 該当アラームのアラーム音を停止する              |
| 他に鳴動中のアラームがある状態で停止する | 次のアラーム通知を表示し、通知音を再生する        |
| スヌーズボタンを押す           | 5分後に再通知する                    |
| スヌーズ回数が3回に達する        | 3回目のスヌーズ後、3分間操作がなければ自動停止する     |
| ブラウザを再読み込みする         | アラーム音および通知を終了し、アラーム一覧に戻る         |
| タブを閉じて再度起動する         | 保存されたアラームを復元してアラーム一覧に戻る           |





## 4. 制約事項

| 項目 | 内容 |
|------|------|
| 時間設定 | 時間は0～23の範囲外は設定できない |
| 分設定 | 分は0～59の範囲外は設定できない |
| 登録上限 | 5件まで |
| 重複登録 | 同じ時刻のアラームは登録できない |
| アラーム音 | アラーム音は固定とし、変更できない |
| スヌーズ | 時間および回数は変更できない |
