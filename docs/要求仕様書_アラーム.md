# アラーム　要求仕様書

## 1. 概要

- ブラウザ上で動作するアラーム機能を作成する

### 1.1 要件
アラームは以下の機能を提供する

- アラームを登録できる
- 登録したアラームを編集できる
- 登録したアラームを削除できる
- アラームの有効・無効を切り替えられる
- 設定時刻になると通知できる
- アラームを停止できる
- アラームをスヌーズできる
- 複数のアラーム通知を管理できる
- アラーム設定を保存できる
- アラームとタイマーを同時に動作させることができる
- 画面を切り替えてもアラームの動作を継続する



## 2. 機能仕様

### 2.1 初期

- アラームは最大５件まで登録できる
- 登録済みアラームがある場合は一覧を確認できる
- 登録済みアラームが存在する場合、アラーム一覧から各アラームの有効・無効状態を切り替えれる


### 2.2 アラーム登録

- 24時間制で時刻を設定できる
- 設定した時刻をアラームとして登録できる
- 登録時は初期状態を有効状態とする
- 入力内容をキャンセルできる


### 2.3 アラーム管理

- 有効状態のアラームのみ設定時刻になると通知する
- 無効状態のアラームは設定時刻になっても通知しない


### 2.4 アラーム編集

- 登録済みのアラームの時間と分を編集できる


### 2.5 アラーム削除

- 登録したアラームを削除できる


### 2.6 アラーム鳴動

- 設定時刻になるとアラーム音を再生する
- アラーム音を停止できる
- 停止操作を行っても、アラームの有効・無効状態は変更しない
- アラームをスヌーズできる
- 複数のアラーム通知が発生した場合、同時に複数のアラーム音を再生しない
- 複数のアラーム通知が発生した場合は、発生順に通知する
- 各通知は個別に停止またはスヌーズする
- 鳴動中の通知を停止した場合、次の通知があればアラーム音を再生する


### 2.7 スヌーズ機能

- ユーザーがスヌーズ操作を行うと、3分後に再通知する
- スヌーズは最大3回まで実行できる
- 3回目の再通知後、3分間ユーザーによる停止操作が行われない場合は、自動でアラーム音と通知を停止する


### 2.8 再読み込み・再起動

- 鳴動中にブラウザを再読み込み・再起動した場合、アラーム音および通知を終了し、アラーム一覧に戻る
- 鳴動中にタブを閉じた場合、アラーム音および通知を終了する


### 2.9 データ管理

- ブラウザを再読み込みしても、登録したアラームを復元する
- 再度起動しても、登録したアラームを復元する




## 3. 制約事項

| 項目 | 内容 |
|------|------|
| 時間設定 | 時間は0～23の範囲とする |
| 分設定 | 分は0～59の範囲とする |
| 登録上限 | 5件まで |
| 重複登録 | 同じ時刻のアラームは登録できない |
| アラーム音 | アラーム音は固定とし、変更できない |
| スヌーズ | 3分・最大3回から変更できない |
