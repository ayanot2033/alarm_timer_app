# アラーム　要求仕様書

## 1. 概要

ブラウザ上で動作するアラーム機能を作成する
ユーザーはアラーム時刻を設定し、設定した時刻になると通知を行う



## 2. 機能仕様

### 2.1 初期状態

- アラームは最大５件まで登録できる
- 登録済みアラームがある場合は一覧を確認できる
- 登録済みアラームが存在する場合、アラーム一覧画面から各アラームの有効・無効状態を確認できる


### 2.2 アラーム登録

- 24時間制の時間選択欄を確認できる
- 0～23までの時間を選択できる
- 0～59までの分を選択できる
- 設定した時間・分をアラームとして登録できる
- 登録時は初期状態を有効として登録する
- キャンセルボタンを押すと入力内容を破棄する
- 登録済みの同じ時刻のアラームは登録できない
- アラームの重複登録は登録できない
- 登録件数が5件の場合はそれ以上は登録できない


### 2.3 アラーム管理

- 登録したアラームを編集できる
- 登録済みアラームごとに有効・無効状態を変更できる
- 有効状態のアラームのみ設定時刻になると通知する
- 無効状態のアラームは設定時刻になっても通知しない
- 登録したアラームを削除できる
- 複数のアラームを同時に有効状態にできる
- アラーム削除時は確認ダイアログが表示される


### 2.4 アラーム鳴動中

- 設定時刻になると固定されたアラーム音を再生する
- アラーム音は停止ボタンが押されるまで継続して再生する
- 停止ボタンを確認できる
- スヌーズボタンを確認できる
- 複数の通知が発生した場合でも、アラーム音は同時に複数再生しない
- 複数のアラーム通知が発生した場合、通知一覧へ発生順に追加して表示する
- 各通知は個別に停止またはスヌーズできる
- 停止した通知以外に鳴動中のアラームがある場合、次のアラーム音を再生する
- すべての鳴動中アラーム音を停止すると、アラーム一覧画面に戻る



### 2.5 スヌーズ機能

- スヌーズボタンを押すと、5分後に再通知する
- スヌーズは最大3回まで実行できる
- スヌーズ中はアラームの編集および削除はできない
- 3回目の再通知後、5分間ユーザーによる停止操作が行われない場合は、自動でアラーム音と通知を停止する




### 2.6 データ管理

- 登録したアラームおよび有効・無効状態をブラウザの保存領域へ保存する
- ブラウザを再読み込みしても、登録済みアラームおよび有効・無効状態を復元する
- 鳴動中にブラウザを再読み込みした場合、通知音および通知画面は終了する
- 鳴動中にブラウザを再読み込みした場合、アラーム一覧画面へ戻る
- ブラウザを再読み込みしても、アラームの有効・無効状態は変更しない



## 3. 操作例

| 操作                   | 表示・結果                        |
| -------------------- | ---------------------------- |
| 追加ボタンを押す             | アラーム設定画面を表示する                |
| 時間・分を選択する            | 選択した時刻を表示する                  |
| 保存ボタンを押す             | アラーム一覧へ追加する                  |
| キャンセルボタンを押す          | 入力内容を破棄し、アラーム一覧画面へ戻る         |
| 既に登録済みの時刻を保存する       | 「同じ時刻のアラームは既に登録されています。」を表示する |
| 登録件数が5件の状態で追加する      | 「登録件数は5件までです。」を表示する          |
| 編集ボタンを押す             | アラーム編集画面を表示する                |
| 時刻を変更して保存する          | 変更した内容でアラーム一覧を更新する           |
| 編集中にキャンセルする          | 編集前の設定内容に戻る                  |
| ON/OFFボタンを押す         | アラームの有効・無効状態を切り替える           |
| 削除ボタンを押す             | 削除確認ダイアログを表示する               |
| 削除確認で削除を選択する         | アラームを削除し、一覧画面を表示する           |
| 削除確認でキャンセルを選択する      | アラームを削除せず一覧画面へ戻る             |
| 設定時刻になる              | アラーム通知画面を表示し、通知音を再生する        |
| 停止ボタンを押す             | 該当アラームの通知音を停止する              |
| 他に鳴動中のアラームがある状態で停止する | 次のアラーム通知を表示し、通知音を再生する        |
| スヌーズボタンを押す           | 5分後に再通知する                    |
| スヌーズ回数が3回に達する        | 3回目の通知後、3分間操作がなければ自動停止する     |
| ブラウザを再読み込みする         | 登録済みアラームを復元して表示する            |





## 4. 制約事項

| 項目 | 内容 |
|------|------|
| 時間設定 | 時間は0～23の範囲外は設定できない |
| 分設定 | 分は0～59の範囲外は設定できない |
| 登録上限 | 5件登録済みの場合は新規登録できない |
| 重複登録 | 同じ時刻のアラームは登録できない |
| アラーム音 | アラーム音は固定とし、変更できない |
| スヌーズ | 時間および回数は変更できない |
