# タイマー　要求仕様書

## 1. 概要

- ブラウザ上で動作するタイマー機能を作成する

### 1.1 要件

タイマーは以下の機能を提供する

- タイマーを設定できる
- 設定した時間からカウントダウンできる
- カウントダウンを一時停止・再開できる
- カウントダウンをキャンセルできる
- カウントダウン終了時に通知できる
- 終了したタイマーを再度開始できる
- アラームとタイマーを同時に動作させることができる
- 画面を切り替えてもタイマーのカウントダウンを継続する
- ブラウザの再読み込み・再起動後はタイマーを初期状態に戻す


## 2. 機能仕様

### 2.1 タイマー設定

- タイマーは1件のみ設定できる
- 時間・分・秒を設定できる


### 2.2 カウントダウン

- 設定した時間からカウントダウンを開始する
- 残り時間は1秒ごとに減少する
- カウントダウンを一時停止できる
- カウントダウンをキャンセルすると、設定した時間に戻る


### 2.3 一時停止

- 一時停止時点の残り時間を保持する
- 保持した残り時間からカウントダウンを再開する
- 一時停止中にキャンセルすると、設定した時間に戻る



### 2.4 タイマー終了

- 残り時間が00:00:00になると通知音を再生する
- 通知開始後、3分間停止操作が行われない場合は、通知音を自動停止する
- 終了したタイマーを再度開始すると、設定した時間からカウントダウンする



### 2.5 再読み込み・再起動

- カウントダウン中にブラウザを再読み込み・再起動した場合、カウントダウンを終了し、カウントダウン開始前に戻る
- 一時停止中にブラウザを再読み込み・再起動した場合、一時停止状態を終了し、カウントダウン開始前に戻る
- タイマー鳴動中にブラウザを再読み込み・再起動した場合、通知を終了し、カウントダウン開始前に戻る




## 3. 制約事項

| 項目    | 内容                          |
| ----- | --------------------------- |
| 設定数  | タイマーは1件のみ設定できる         |
| 開始条件  | 00:00:00ではタイマーを開始できない        |
| 操作制限  | カウントダウン中は時間・分・秒を変更できない      |
| 入力制限  | 時間・分・秒は選択式とし、直接入力できない             |
| 選択制限  | 時間は0～23、分・秒は0～59の範囲とする|
