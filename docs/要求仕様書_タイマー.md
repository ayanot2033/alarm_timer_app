# タイマー　要求仕様書

## 1. 概要

ブラウザ上で動作するタイマーアプリを作成する
ユーザーが設定した時間からカウントダウンを行い、00:00:00になると通知を行う



## 2. 機能仕様

### 2.1 初期状態

- タイマーは1件のみ設定できる
- 時間（0～23）、分（0～59）、秒（0～59）をプルダウンから選択して設定できる
- 時間・分・秒のいずれか1つ以上に値が設定されている場合、開始ボタンを押下できる
- 開始ボタン押下時、設定した時間を残り時間としてカウントダウンを開始する


### 2.2 カウントダウン中

- 残り時間は1秒ごとに減少する
- カウントダウン中は時間・分・秒の設定欄を操作できない
- 一時停止ボタン押下時、カウントダウンを一時停止する
- キャンセルボタン押下時、設定画面へ戻り、開始前に設定した時間を表示する
- ブラウザ画面を切り替えてもカウントダウンを継続する


### 2.3 一時停止中

- 一時停止時点の残り時間を保持する
- 開始ボタン押下時、保持した残り時間からカウントダウンを再開する
- キャンセルボタン押下時、設定画面へ戻り、開始前の設定時間を確認できる



### 2.4 終了時

- 残り時間が00:00:00になると通知音を再生する
- タイマー終了のポップアップを表示する
- 停止ボタン押下時、通知音を停止し設定画面へ戻る
- もう一度開始ボタン押下時、開始時に保持した設定時間から再度カウントダウンを開始する
- もう一度開始ボタン押下時、通知音を停止する



### 2.5 データ管理

- タイマーの設定時間および実行状態をブラウザの保存領域へ保存する
- カウントダウン中にブラウザを再読み込みした場合、タイマーの状態を復元する
- カウントダウン中にブラウザを再読み込みした場合、経過時間を考慮して残り時間からカウントダウンを継続する
- 一時停止中にブラウザを再読み込みした場合、一時停止状態および残り時間を保持する
- タイマー終了後にブラウザを再読み込みした場合、設定状態へ戻る



## 3. 操作例

| 操作                    | 表示・結果                          |
| --------------------- | ------------------------------ |
| 時間・分・秒を選択する           | 選択した時間を表示する                    |
| 00:00:00以外の時間を設定する    | 開始ボタンを押下できる                    |
| 開始ボタンを押す              | 設定した時間からカウントダウンを開始する           |
| カウントダウン中              | 残り時間を1秒ごとに更新する                 |
| カウントダウン中に一時停止ボタンを押す   | カウントダウンを一時停止し、残り時間を保持する        |
| 一時停止中に開始ボタンを押す        | 保持した残り時間からカウントダウンを再開する         |
| カウントダウン中にキャンセルボタンを押す  | 設定画面へ戻り、開始前に設定した時間を表示する        |
| 一時停止中にキャンセルボタンを押す     | 設定画面へ戻り、開始前に設定した時間を表示する        |
| 残り時間が00:00:00になる      | 通知音を再生し、終了通知画面を表示する            |
| 終了通知画面で停止ボタンを押す       | 通知音を停止し、設定画面へ戻る                |
| 終了通知画面でもう一度開始ボタンを押す   | 通知音を停止し、設定した時間から再度カウントダウンを開始する |
| カウントダウン中にブラウザを再読み込みする | 残り時間からカウントダウンを継続する             |
| 一時停止中にブラウザを再読み込みする    | 一時停止状態および残り時間を復元する             |
| 終了通知中にブラウザを再読み込みする    | 通知音を停止し、設定画面へ戻る                |




## 4. 制約事項

| 項目    | 内容                          |
| ----- | --------------------------- |
| 開始条件  | 00:00:00では開始ボタンを押下できない            |
| 操作制限  | カウントダウン中は時間・分・秒を変更できない      |
| 入力制限  | 時間・分・秒は直接入力できない             |
| 選択制限  | 時間は0～23、分・秒は0～59以外の値は選択できない |
