# アラームシーケンス図

```mermaid
%%{init: {
  "theme": "dark"
}}%%

sequenceDiagram

    actor ユーザー
    participant アラーム一覧画面
    participant アラーム設定・編集画面
    participant アラーム処理
    participant localStorage
    participant 通知処理
    participant アラーム通知画面

    ユーザー->>アラーム一覧画面: 追加操作
    アラーム一覧画面->>アラーム設定・編集画面: 設定画面を表示
    ユーザー->>アラーム設定・編集画面: 時間・分を設定
    ユーザー->>アラーム設定・編集画面: 保存ボタンを押下
    アラーム設定・編集画面->>アラーム処理: アラーム設定を登録

    alt 登録可能
        アラーム処理->>localStorage: アラーム設定を保存
        localStorage-->>アラーム処理: 保存完了
        アラーム処理-->>アラーム一覧画面: 登録完了
        アラーム一覧画面-->>ユーザー: 登録したアラームを表示

    else 5件登録済み
        アラーム処理-->>アラーム設定・編集画面: 登録上限エラー
        アラーム設定・編集画面-->>ユーザー: 登録件数は5件までです

    else 同じ時刻が登録済み
        アラーム処理-->>アラーム設定・編集画面: 重複エラー
        アラーム設定・編集画面-->>ユーザー: 同じ時刻のアラームは既に登録されています
    end

    Note over アラーム処理: 設定時刻まで待機

    アラーム処理->>通知処理: 設定時刻になったことを通知
    通知処理->>アラーム通知画面: 通知を表示
    通知処理->>通知処理: アラーム音を再生

    alt 停止操作
        ユーザー->>アラーム通知画面: 停止操作
        アラーム通知画面->>通知処理: 通知停止を要求
        通知処理->>通知処理: アラーム音を停止
        通知処理-->>アラーム通知画面: 通知を終了
        アラーム通知画面-->>アラーム一覧画面: アラーム一覧に戻る

    else スヌーズ操作
        ユーザー->>アラーム通知画面: スヌーズ操作
        アラーム通知画面->>アラーム処理: スヌーズを要求
        アラーム処理->>アラーム処理: スヌーズ回数を加算
        Note over アラーム処理: 3分待機
        アラーム処理->>通知処理: 再通知を要求
        通知処理->>アラーム通知画面: 通知を表示
        通知処理->>通知処理: アラーム音を再生
        Note over アラーム処理: 3回目のスヌーズ後
        Note over 通知処理: 3分間操作がない
        通知処理->>通知処理: アラーム音を停止
        通知処理-->>アラーム通知画面: 通知を終了
        アラーム通知画面-->>アラーム一覧画面: アラーム一覧に戻る
    end

    alt ブラウザを再読み込み・再起動した場合
        ユーザー->>アラーム処理: ブラウザを再読み込み・再起動
        アラーム処理->>localStorage: アラーム設定を取得
        localStorage-->>アラーム処理: 保存済みアラーム設定
        アラーム処理-->>アラーム一覧画面: アラーム設定を復元
        アラーム一覧画面-->>ユーザー: 登録済みアラームを表示
    end
